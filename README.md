## 目前價格資料模式
v1.0.0 先使用「各通路搜尋入口 + 人工填入售價 + 自動到手價計算」。

原因是多數購物網站會有：
- CORS 限制
- 反爬蟲
- 登入 / Cookie
- 動態價格
- 會員價
- 不同活動頁面價格

因此不能可靠地只靠 GitHub Pages 前端直接抓所有網站售價。

## 下一階段建議
v1.1.0 可以在 server.js 的 `/api/search` 接：
1. Google Shopping / SerpAPI / Serper 類搜尋 API
2. 官方商城 API（有提供時）
3. 合法合作資料源
4. 自建後端爬蟲（需逐站確認 robots / 使用條款，並處理防爬策略）

## GitHub
此專案可放 GitHub，但因包含 Node.js 後端，**不能只用 GitHub Pages 執行後端**。
前端可放 Pages，後端可部署到 Render / Railway / Vercel / Cloudflare Workers 等平台。

若改成純前端版，則只能保留通路搜尋連結、手動價格輸入與到手價計算。
