### 分類自動勾選通路
當「商品類型」下拉選單變更時，系統會自動勾選對應通路。

例如：

- 3C資訊：
  - PChome
  - momo
  - Yahoo
  - 蝦皮
  - 燦坤3C
  - 全國電子
  - 順發3C
  - NOVA
  - 欣亞
  - 良興
  - 原價屋
  - AUTOBUY
  - 三井3C
  - 日本橋

- 美妝日用：
  - momo
  - Yahoo
  - 蝦皮
  - Costco
  - 寶雅
  - 康是美
  - 屈臣氏
  - Tomod's
  - 松本清
  - 莎莎

使用者仍可手動取消或勾選任何通路。
