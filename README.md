# 全通路比價中心 v1.3.1

## 本版修正
- 移除結果按鈕對 Google Shopping / Google 搜尋的依賴。
- 「前往確認售價」統一改為各通路自己的搜尋頁。
- 手機分類增加異常低價過濾，避免 1 元、月租、訂金等誤判為最低價。
- 保留 Serper Shopping 作為價格參考來源，但跳轉不再依賴 Google Shopping。
- 手機、3C、美妝等分類仍可自動勾選相關通路。
