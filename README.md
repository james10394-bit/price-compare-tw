# 全通路比價中心 v1.3.0

## 本版重點

### 1. 比價通路改成下拉式多選
不再把二十幾個通路全部攤在畫面上。
下拉選單內可：
- 依分類推薦
- 全選
- 清除
- 個別勾選

### 2. 手機通路新增

### 3. 手機分類自動推薦
選「手機平板」後，會自動勾選：
三大電信、主要品牌官方、大型電商、手機零售與主要3C通路。

### 4. 價格可信度
Google Shopping 抓到的價格標示為「搜尋參考價」。
系統加入型號匹配分數：
- 🟢 型號高度符合
- 🟡 可能同系列，建議確認規格
- 🔴 規格符合度偏低

實際成交價仍以通路頁面為準。
